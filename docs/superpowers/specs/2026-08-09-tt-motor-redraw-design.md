# TT Motor 精準重畫設計

## 目標

以 `3d_models/high_res/tt-motor-dimension.jpeg` 為尺寸權威、`3d_models/high_res/tt-motor.glb` 為外觀參考，重畫 NexCAD 的 TT 減速馬達。高解析 STL、程序化碰撞模型及智能小車定位必須使用一致的尺寸與座標基準。

## 輸入與限制

- 尺寸圖定義主要外形、輸出軸及孔位尺寸。
- GLB 提供零件關係、外觀細節及交叉檢查；其包圍盒約為 `37.1 × 22.5 × 69.9 mm`。
- 原 GLB 含 511 個 mesh、約 167MB，不直接作為 NexCAD runtime 資產。
- 保留現有 OpenSCAD 人機協作流程；`tt-motor.scad` 是來源，binary STL 是高解析 viewport 衍生資產。
- 不新增依賴，不改造 NexCAD 的高解析模型載入器。

## 尺寸契約

單位均為毫米。NexCAD 座標維持：

- 長軸為 X；馬達罐位於負 X，齒輪箱圓頭位於正 X。
- 雙出軸沿 Y。
- 高度沿 Z，底面為 `Z = 0`。
- 原點位於齒輪箱主體包圍盒的 X/Y 中心及底面。

關鍵尺寸：

| 特徵 | 目標尺寸 |
| --- | --- |
| 整體包圍盒 | 約 `69.9 × 37.1 × 22.5` |
| 圖紙主體長度 | `64.5` |
| 齒輪箱厚度（Y） | `18.8` |
| 齒輪箱側面高度（Z） | `22.3` |
| 馬達罐外徑 | `22.4` |
| 雙出軸總寬 | 約 `37.0` |
| 輸出軸直徑 | `5.4` |
| D 型平面寬 | `3.7` |
| 輸出軸中心至齒輪箱圓頭端 | `11.28` |
| 齒輪箱側孔 | `2 × Ø3.0`，中心距 `17.3` |
| 前端側孔 | `Ø2.8` |

圖紙沒有標示的細小倒角、螺絲頭深度、接縫寬度及端子厚度，以 GLB 比例推定；這些只影響視覺，不得改變關鍵包圍盒或軸心。

## 高解析模型

重構現有 `public/parts/tt-motor/tt-motor.scad` 的命名參數及模組，保留能從圖紙或 GLB 支持的幾何：

- 黃色兩片式齒輪箱，包含圓頭、接縫及主要凸台；
- 銀色圓柱馬達罐及黑色尾蓋；
- 包覆馬達罐的金屬固定片；
- 兩個端子；
- 雙側 D 型輸出軸及軸套；
- 兩個 `Ø3` 側孔、前端 `Ø2.8` 側孔；
- 側面螺絲、通風孔和主要殼體細節。

省略 GLB 中不影響辨識或裝配的微小壓紋、過細網格和內部齒輪。OpenSCAD 色彩只供來源預覽；NexCAD 現有 STL loader 仍以單一 runtime 材質顯示。

STL 必須以 binary 格式輸出，避免 `STLLoader` 讀取大型 ASCII STL 時令 Canvas 失敗。

## 程序化碰撞模型

`src/parts/library.ts` 的 `tt-motor` 定義改為與高解析模型相同的原點、軸心與外形包圍盒。程序化模型保留少量基本幾何：齒輪箱、馬達罐及雙出軸；不複製螺絲、端子與接縫等純視覺細節。

碰撞模型必須保守涵蓋高解析模型，但不可沿長軸或輸出軸方向明顯超出圖紙尺寸。`clearanceHeight` 至少覆蓋馬達罐 `22.4 mm` 高度。

圖紙中的三個孔均沿 Y 軸穿過側面。NexCAD 目前的 `mountingHoles` 僅表示 Z 軸底孔，因此：

- 高解析模型準確畫出側孔；
- 程序化模型不把側孔登記為 `mountingHoles`；
- 產生外殼時不為這些側孔建立底部螺絲柱。

## 智能小車定位

`src/parts/presets.ts` 不再依賴舊 TT Motor 軸心常數。新軸心本地 X/Z 由更新後的程序化定義確認，並用於：

- 讓馬達輸出軸 X 與車輪中心 X 對齊；
- 讓馬達輸出軸世界 Z 與車輪中心高度對齊；
- 保持 2WD 與 4WD 馬達貼在底盤頂面。

既有已儲存專案不自動遷移節點位置；新建立的智能小車使用新定位。這與現有零件幾何更新的向後相容策略一致。

## 檔案變更

- 修改 `public/parts/tt-motor/tt-motor.scad`：精準參數來源。
- 重新生成 `public/parts/tt-motor/tt-motor.stl`：高解析 viewport 資產。
- 修改 `public/parts/tt-motor/README.md`：尺寸、原點、生成及驗證說明。
- 修改 `src/parts/library.ts`：程序化碰撞與孔位語義。
- 修改 `src/parts/ttMotor.test.ts`：包圍盒、軸心、軸徑及無底部孔驗證。
- 修改 `src/parts/presets.ts` 及 `src/parts/presets.test.ts`：智能小車軸心定位。

## 驗證

遵循 TDD，先更新測試並確認其對舊模型失敗，再修改來源：

1. 程序化幾何包圍盒接近 `69.9 × 37.0 × 22.4 mm`。
2. 輸出軸直徑接近 `5.4 mm`，軸心高度接近 `11.2 mm`。
3. `mountingHoles` 不包含錯誤的 Z 軸底孔。
4. 2WD、4WD 的馬達軸心與對應車輪 X/Z 重合。
5. OpenSCAD 成功生成 binary STL。
6. STL 包圍盒及方向符合尺寸契約。
7. CAD Explorer 以等角、側面及頂面視圖檢查外觀；任何視覺問題都以尺寸或包圍盒檢查確認。
8. TT Motor、零件庫、智能小車 preset 及 TypeScript 測試全部通過。

## 驗收條件

- 高解析模型可辨認為參考 GLB 的同款 TT Motor，具備平衡版細節。
- 高解析與程序化模型使用相同原點、長軸、軸方向和軸心。
- 關鍵尺寸符合圖紙，整體包圍盒符合 GLB 尺度。
- 側孔不再誤導外殼生成器建立底部螺絲柱。
- 新生成的 2WD/4WD 智能小車中，馬達軸與車輪中心對齊。
- runtime 資產遠小於 167MB 參考 GLB，並能由現有 STL loader 正常載入。
