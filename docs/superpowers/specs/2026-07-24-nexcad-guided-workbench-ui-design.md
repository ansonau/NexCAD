# NexCAD Guided Workbench UI 設計規格

日期：2026-07-24
狀態：已與用戶確認

## 1. 摘要

NexCAD 的主界面採用 **Guided Workbench**：保留專業 CAD 工作區，同時以明確流程引導降低新手迷路感。

已確認方向：

- **界面架構**：3 欄式工作台
- **左欄模型**：流程優先 Action Rail
- **視覺語氣**：Clean Engineering
- **右上角全局控制**：乾淨式 `Help`、語言、Settings、User

## 2. 設計目標

- 讓新手知道下一步該做甚麼，不面對空白或抽象工具列。
- 保留 CAD 工具的可信度和精準感，不變成過度教學化的 wizard。
- 把「工作流程」、「3D 操作」、「參數設定」分區，減少操作混亂。
- 右上角只放全局功能，避免和建模操作競爭注意力。

## 3. 主版面

主界面為三欄式：

| 區域 | 用途 |
|---|---|
| 左欄 | Action Rail：流程引導、下一步、簡化物件清單 |
| 中央 | 3D viewport、主要 CAD 操作、場景提示 |
| 右欄 | Context Panel：選取物件、外殼、位置、尺寸等參數 |

中央 viewport 仍是視覺重心。左右欄應輔助操作，不應壓縮或搶走 3D 工作區。

## 4. 左欄：流程優先 Action Rail

左欄主打「下一步」，不是傳統 scene tree 優先。

建議流程：

1. 加入零件
2. 調整位置
3. 產生外殼
4. 檢查孔位 / 螺絲柱
5. 匯出 STL

左欄下半部可保留簡化物件清單，方便選取場景物件。

行為要求：

- 目前步驟需高亮。
- 每一步提供一句短說明。
- 空專案時左欄應顯示明確開始動作，例如「加入第一個零件」。
- 智能小車、產生外殼等複雜流程可在 Action Rail 內使用局部 wizard，但不要讓整個 app 變成 wizard。

## 5. 中央：3D 工作區

中央區維持乾淨、專注。

要求：

- 保留淡格線地面與清晰的選取狀態。
- 在 viewport 內顯示輕量「下一步」提示，例如「下一步：放置電子零件」。
- 主要建模工具仍可留在 top toolbar，例如新增零件、移動、外殼、匯出 STL。
- 不在右上角放建模工具。

## 6. 右欄：Context Panel

右欄只處理當前上下文：

- 選取零件時：位置、旋轉、尺寸、固定方式。
- 選取外殼時：壁厚、邊距、上蓋類型、螺絲柱、螺絲孔。
- 未選取時：顯示簡短提示或專案狀態，不顯示空白面板。

右欄應避免混入全局設定，例如語言、帳戶、通用偏好設定。

## 7. 頂部工具列與右上角全局控制

頂部工具列分兩組：

- 中間 / 左側：建模與流程相關工具。
- 右上角：全局功能。

右上角採用乾淨式排列：

```text
?   繁中 ▾   ⚙   User
```

含義：

| 控制 | 用途 |
|---|---|
| `?` | Help、快捷鍵、基本教學 |
| `繁中 ▾` | 多語言下拉，顯示目前語言 |
| `⚙` | Settings |
| `User` | 使用者入口，圓形 initials 或 avatar |

User button 第一版只做輕量入口：

- 未登入：顯示 user icon。
- 已登入：顯示 initials 或 avatar。
- 可先不做完整帳戶系統、雲端同步或 billing。

Settings 第一版可包含：

- 單位顯示：mm
- 語言
- 顯示格線 / 輔助線
- 預設匯出格式

## 8. 視覺語氣：Clean Engineering

視覺方向為明亮、精準、可信、友好。

要求：

- Light theme 優先。
- 白色或近白面板。
- 淡藍灰背景與細格線。
- 大圓角、細邊框、輕陰影。
- 單一主強調色用於主要操作、選取狀態和流程高亮。
- 文案應直接說明下一步，不使用過度抽象術語。

不採用：

- 深色優先界面。
- 過度遊戲化或幼齒的 maker 風格。
- 華麗但缺乏狀態提示的裝飾性 UI。

## 9. 響應式原則

桌面優先顯示完整三欄。

較窄畫面可採用：

- 左欄收合為流程 drawer。
- 右欄收合為底部 sheet 或浮動 panel。
- 右上角全局控制保留，但可縮成 icon + 語言短碼。

觸控目標不得小於 44px。

## 10. 非目標

本規格不包含：

- 完整帳戶系統
- 雲端同步
- 深色模式
- 全 app wizard 化
- 新增設計系統套件或第三方 UI framework
- 重寫 3D viewport 或幾何邏輯

## 11. 驗收標準

- 主界面清楚呈現左流程、中 3D、右參數。
- 左欄能顯示目前步驟與下一步提示。
- 右上角包含 `Help`、語言下拉、Settings、User button。
- 建模工具不混入右上角全局控制。
- 空狀態不再讓用戶面對空白面板。
- 桌面和窄畫面都可正常操作。
