# NexCAD 手動量度工具設計

## 目標

在 viewport 顯示工具列加入手動量度模式，讓使用者以兩次點擊量度任意兩個物件表面位置。工具同時支援自由點選與幾何吸附，並以清晰的 CAD 標註顯示直線距離及三軸差值。

## 範圍

- 點擊物件表面任意位置設定 A、B 兩點。
- 可切換吸附；吸附目標包括孔中心、頂點及邊線。
- 顯示直線距離、`ΔX`、`ΔY`、`ΔZ`，單位為毫米。
- 預設只保留最新一組目前量度。
- 可固定目前量度並繼續建立下一組。
- 固定標註只保留於目前工作階段，不寫入 NexCAD 專案檔。
- 支援重新量度、取消未完成量度及退出模式。

不包含角度、面積、半徑、弧長、永久儲存、標註命名或匯出。

## 使用者流程

1. 使用者在 viewport 顯示工具列按下「手動量度」。
2. 工具進入啟用狀態，顯示小型浮動控制；物件選取與 Gizmo 暫停。
3. 第一次點擊設定 A 點。移動游標時，viewport 即時預覽 A 點至目前候選點的距離。
4. 第二次點擊設定 B 點，完成目前量度。
5. 使用者可以：
   - 直接點擊新 A 點，取代未固定的目前量度；
   - 按「固定標註」保留結果並開始下一組；
   - 按「重新量度」清除目前 A/B 點；
   - 按 `Esc` 取消未完成量度；
   - 再按工具列按鈕或浮動控制的退出按鈕離開模式。
6. 退出後固定標註仍顯示，直到頁面重新載入或使用者清除它們。

## 介面設計

手動量度按鈕整合於現有 `ViewToggles`，與 X-Ray、Wireframe、Dimensions 及 High Resolution 使用相同視覺語言。量度模式啟用時，viewport 顯示不遮擋主要工作區的小型控制列，包含：

- 吸附開關；
- 固定標註；
- 重新量度；
- 清除固定標註；
- 退出。

量度標註沿用現有尺寸線的顏色、箭頭及大字風格。A、B 點以清楚但不搶眼的端點標記表示。數值卡以直線距離為主資訊，`ΔX / ΔY / ΔZ` 為次資訊。游標停在有效吸附候選點時，候選點會高亮，以便使用者預判實際落點。

## 狀態與資料

量度資料屬 viewport 暫態狀態，放在現有 `viewStore`，供工具列、浮動控制及 viewport 共用：

- `measureActive`: 是否處於手動量度模式；
- `measureSnap`: 是否啟用吸附；
- `measureStart`: A 點或空值；
- `measureEnd`: 已完成的 B 點或空值；
- `measurePreview`: 游標目前候選點或空值；
- `pinnedMeasurements`: 已固定量度陣列。

每組量度只保存 A、B 的 CAD 世界座標。距離及三軸差值由座標即時計算，不重複儲存衍生值。重新載入應用程式時，這些資料恢復預設空狀態。

## 點選與吸附

React Three Fiber 的 mesh 點擊事件提供表面交點。Viewport 會把 Three.js 世界座標轉回 NexCAD 的 CAD 座標，再交給量度狀態。

吸附啟用時，以游標附近約 14px 的螢幕距離尋找候選點，優先順序如下：

1. 已知零件孔中心；
2. 相交三角形的頂點；
3. 相交三角形邊線上的最近點；
4. 原始物件表面交點。

固定螢幕距離使吸附手感不受模型縮放及相機遠近影響。關閉吸附時直接採用表面交點。點擊空白位置不改變目前量度。

## 元件邊界

- `ViewToggles`：啟用或退出手動量度模式。
- `Viewport`：接收 pointer 事件、解析候選點、暫停一般選取並渲染量度。
- `viewStore`：保存工作階段量度狀態及提供最小狀態操作。
- 純量度 helper：計算兩點距離、三軸差值及吸附候選點，保持可獨立測試。
- 現有尺寸標註元件：重用線段、箭頭及 HTML 標籤表現，不另建渲染系統。

## 邊界情況

- A、B 點重合或距離小於 `0.01 mm` 時不完成量度。
- 未設定完整 A/B 點時，「固定標註」停用。
- 沒有吸附候選點時回落到表面交點，不阻塞操作。
- 量度模式啟用時不改變場景 selection，也不啟動移動或旋轉 Gizmo。
- 模型隱藏、刪除或重建後，固定標註仍按固定時的座標顯示；它們不綁定物件。
- `Esc` 先取消未完成量度；沒有未完成量度時退出模式。

## 測試策略

遵循 TDD，先建立會因功能不存在而失敗的測試：

- 純函式測試：直線距離、帶正負號的 `ΔX / ΔY / ΔZ`、重合點拒絕及吸附優先順序。
- Store 測試：啟用、第一點、第二點、取代目前量度、固定、重新量度、清除固定標註及退出。
- E2E 測試：工具列可進入模式、可切換吸附、兩次點擊產生標籤、固定後可開始新量度、`Esc` 行為正確。
- 回歸驗證：TypeScript、既有 Vitest 測試及 viewport smoke tests 全部通過。

## 驗收條件

- 使用者可在任意兩個可見物件表面點完成量度。
- 啟用吸附時可以吸附孔中心、頂點或邊線；無候選點時仍可自由點選。
- 完成後清楚顯示毫米直線距離及 `ΔX / ΔY / ΔZ`。
- 最新量度可固定，且固定標註不會被下一次量度取代。
- 工具不遮擋主要 viewport，不干擾正常選取或 Gizmo。
- 重新載入專案後固定標註不保留。
